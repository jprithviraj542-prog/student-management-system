# Student Performance Analyser

## Overview
A Python-based project that analyses student academic performance
and attendance using CSV files.

## Features
- View all student records
- Search students by name
- Display the top 3 students
- Identify students with low attendance
- Calculate average marks and grades
- Save analysis results to a CSV file

## Technologies Used
- Python
- CSV file handling
- OS module

## Project Files
- analyzer.py — Main Python program
- students.csv — Student dataset
- results.csv — Generated analysis results

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

   python analyzer.py
